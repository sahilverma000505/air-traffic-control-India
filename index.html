📍 1. What is an Airport Graph?

Imagine India is a giant coloring book! Every airport (Delhi, Mumbai, Bengaluru) is a dot. Every flight corridor is a pencil line connecting two dots with a number telling us how many kilometers long it is.

🧶 2. What is Prim's Algorithm?

Imagine you have 16 toy houses on the floor and a ball of string. You want to tie every single house together so toy cars can visit any house, using the shortest piece of string! Prim's algorithm starts at one house, grabs the closest untied house, and repeats until all 16 are connected without any redundant loops.

🍽️ 3. What is Client-Server-Database?

Think of a restaurant!
• Client (You in Browser): The customer ordering food.
• Server (Python/Java): The friendly waiter who takes your order slip to the kitchen.
• Database (SQLite/MySQL): The kitchen pantry where all airport and route records are kept fresh!

📖 4. What is JDBC & Hibernate?

The Java Waiter speaks Java language, but the Database Pantry speaks SQL language!
• JDBC is like sending a handwritten note in SQL.
• Hibernate ORM is like an automatic translator that turns Java Objects into database tables with zero effort!

Prim's Algorithm Pseudocode:

2 V_new = {s}, T = ∅, Q = MinHeap()
3 for each edge (s, v) ∈ E: Q.insert(s, v, w(s,v))
4 while |V_new| < |V| and not Q.isEmpty():
5 (u, v, dist) = Q.extractMin() // Greedy choice
6 if v ∈ V_new then continue // Avoid cycle
7 V_new = V_new ∪ {v}; T = T ∪ {(u, v)}
8 for each neighbor w of v where w ∉ V_new:
9 Q.insert(v, w, w(v, w)); return T

How JDBC & Hibernate Work in this Project

1. JDBC (Java Database Connectivity): Uses AirportJdbcDao.java to send direct SQL queries like:
SELECT * FROM airway_routes WHERE is_active = 1
and reads raw ResultSet rows directly into Java memory.

2. Hibernate ORM: Eliminates SQL boilerplate by mapping the database tables to Java Classes using JPA annotations:
@Entity @Table(name="airports") public class Airport { ... }
Hibernate runs HQL queries like FROM Airport and returns clean typed Java objects ready for Prim's algorithm!
